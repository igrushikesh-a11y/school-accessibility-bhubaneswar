# School Accessibility Analysis — Bhubaneswar

GIS Lab End Semester Project
IIT Kharagpur | Master of City Planning | 2025-26

## What this does
Analyses spatial inequality in government school accessibility
across 67 BMC wards using isochrone modelling and K-Means clustering.

## How to run

1. Install dependencies:
   pip install -r requirements.txt

2. Run the script:
   python school_accessibility.py

3. Outputs will be saved in the outputs/ folder.

## Data Sources
- Ward boundary and school data: BhubaneswarOne / BMC GIS Cell
- Population: Census of India 2011
